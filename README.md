# 灰猫地图

基于百度地图与百度导航 SDK 的 Android 地图/导航应用，支持微信位置转发，并提供 Wear OS 独立适配模块。Android Auto 当前暂时移除。

## 功能

- 地图定位与 POI 搜索
- 驾车路线规划和内置导航
- Wear OS 基础适配（`:wear` 模块）
- 微信位置代理转发
- 家、公司和周边快捷入口

## 隐私政策

本隐私政策适用于灰猫地图 Android 应用及其配套微信位置转发 APK。灰猫地图是一款地图和导航工具，应用本身不运营用户账号系统，不建设独立服务器存储用户个人资料，也不会出售用户数据。

### 我们收集或处理的信息

为提供地图、定位、路线规划、导航和 Android Auto 显示功能，应用可能在设备本地或通过集成的地图/导航 SDK 处理以下信息：

- 设备位置信息：用于显示当前位置、搜索周边地点、规划路线、导航和车机端路线指引。
- 搜索和路线信息：例如用户输入的地点、起点、终点、途经点、路线规划结果和导航状态。
- 应用配置数据：例如用户设置的百度地图 Android AK、家/公司快捷地址、导航偏好和本地缓存。
- 设备和应用运行信息：例如应用版本、Android 版本、设备能力、崩溃或错误信息，用于兼容性和故障排查。

灰猫地图不会要求用户注册账号，也不会主动收集姓名、邮箱、电话号码、通讯录、短信、照片或付款信息。

### 信息如何使用

上述信息仅用于：

- 在手机端显示地图、定位和导航；
- 在 Android Auto 车机端显示路线指引、地图画面和导航状态；
- 根据用户操作打开或转发微信位置到灰猫地图；
- 保存用户在本机上的应用设置；
- 修复问题、提升稳定性和兼容性。

### 第三方服务

灰猫地图使用百度地图和百度导航相关 SDK 来实现地图显示、地点搜索、路线规划、定位和导航能力。用户在使用这些功能时，相关位置、搜索、路线、设备和网络信息可能会由百度 SDK 按其隐私政策进行处理。

请同时阅读百度相关隐私政策和 SDK 个人信息处理规则。第三方 SDK 的数据处理行为由相应服务提供方负责。

### 数据存储和共享

- 应用设置、快捷地址和部分缓存数据主要存储在用户设备本地。
- 灰猫地图项目本身不搭建后台服务器保存用户位置轨迹、搜索历史或账号资料。
- 除了为实现地图、定位、路线规划和导航而调用第三方地图 SDK/服务外，我们不会出售、出租或向广告商共享用户个人信息。
- 如果法律法规、监管要求或保护用户与公众安全所必需，可能需要依法配合相关请求。

### 权限说明

应用可能请求以下 Android 权限，具体以安装包清单和系统弹窗为准：

- 位置权限：用于定位、路线规划和导航。
- 网络权限：用于访问地图、搜索、路线规划、导航和相关在线服务。
- 前台服务/通知权限：用于导航过程中保持服务运行并显示导航状态。
- Android Auto / 车载相关能力：用于在车机屏幕显示导航界面。

用户可以在 Android 系统设置中随时撤销相关权限。撤销位置或网络权限后，地图、定位、路线规划和导航功能可能无法正常使用。

## 构建

1. 使用 Android Studio 或 Gradle，JDK 17。
2. 在应用设置中配置百度地图 Android AK。
3. 百度 AK 的包名需包含 `com.huimao.map`，SHA-1 需与实际签名证书一致。
4. 本项目依赖的百度本地 AAR/so 文件体积较大；请确认你有权使用并分发相关 SDK。

```bash
gradle assembleRelease
```

## 微信位置转发

配套转发器源码位于仓库的 `redirector/` 模块。每次 GitHub Release 会同时提供三个 APK：

- 百度地图入口：包名 `com.baidu.BaiduMap`
- 高德地图入口：包名 `com.autonavi.minimap`
- 腾讯地图入口：包名 `com.tencent.map`

三个版本都会通过：

```text
baidunaviauto://navigate?lat=...&lng=...&name=...
```

启动灰猫地图。

> 代理 APK 与对应官方地图使用相同包名，不能同时安装；只需安装一个与手机现有地图不冲突的版本。旧腾讯 1.4 与当前固定签名不同，升级 1.5 时需先卸载旧代理；之后可覆盖升级。

## Android Auto 混合导航架构

- 底图：独立道路瓦片渲染，不嵌入百度 MapView
- 路线：百度规划路线坐标
- 位置：百度 BD09LL 定位
- 方向与速度：百度导航回调
- 转向距离与文字：百度 `BNaviInfo + GuidePanelMessage`
- 剩余距离与时间：百度 `onRemainInfoUpdate`
- 车机界面：Android Auto `NavigationTemplate`
