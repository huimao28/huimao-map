# 灰猫地图隐私政策

**生效日期：2026-08-31**  
**适用版本：灰猫地图 1.1.7 及后续版本**

本隐私政策适用于灰猫地图手机端 Android 应用、Wear OS 配套应用，以及配套的微信位置转发插件（合称“本应用”）。

灰猫地图是一款地图与导航工具。本项目不提供用户账号注册服务，不运营自建服务器存储用户的位置轨迹、搜索历史或个人资料，也不会出售用户个人信息。

## 1. 我们处理的信息

为实现地图、定位、搜索、路线规划、导航和手表导航信息显示，本应用可能在设备本地或通过集成的第三方 SDK 处理以下信息：

- **位置信息**：包括设备当前位置、方向、速度、定位精度与定位时间，用于显示当前位置、周边搜索、规划路线和导航。
- **搜索与路线信息**：包括输入的地点、起点、终点、途经点、路线规划结果、导航指令、道路名称、剩余距离与预计时间。
- **应用配置与本地数据**：包括百度地图 Android AK、家/公司地址、导航偏好、应用设置与必要缓存。
- **设备和运行信息**：包括应用版本、Android 版本、设备能力、网络状态以及崩溃或错误信息，用于兼容性判断和故障排查。
- **Wear OS 导航状态**：当用户使用 Wear OS 配套应用时，手机端会向已配对手表同步必要的导航状态，例如是否正在导航、下一步指令、转向距离、当前道路、剩余距离和剩余时间。

本应用不会主动读取或收集姓名、邮箱、电话号码、通讯录、短信、照片、支付信息或其他与地图导航无关的个人信息。

## 2. 信息的使用方式

我们仅将上述信息用于：

- 在手机端提供地图显示、定位、地点搜索、路线规划和导航；
- 根据用户操作处理微信位置转发并打开相应导航路线；
- 在 Wear OS 配套应用中显示手机端当前导航状态；
- 在本机保存用户选择的地址、配置和必要缓存；
- 排查故障、提升稳定性、兼容性与使用体验；
- 在法律法规要求或保护用户与公众安全确有必要时，依法配合相关请求。

## 3. Wear OS 配套应用

Wear OS 应用是手机端灰猫地图的非独立配套应用，需与已配对的手机共同使用。

- 导航信息通过 Google Play services Wearable Data Layer 在手机与已配对手表之间传输。
- 项目不搭建服务器中转或保存该同步数据。
- 手表端不提供独立路线规划、地点搜索或独立地图导航功能。
- 用户可停止手机端导航、断开设备配对、清除应用数据或卸载应用，以停止后续同步。

## 4. 微信位置转发插件

微信位置转发插件只在用户主动触发位置分享或位置打开操作时，将位置参数转换为灰猫地图可处理的深链接。

插件不建立账号体系，不建立自有服务器保存位置内容，也不将位置用于广告或营销。插件使用与对应地图应用相同的包名，安装前请理解其与官方地图应用不能同时安装的限制。

## 5. 第三方服务

本应用使用百度地图、百度定位和百度导航相关 SDK 提供地图、定位、搜索、路线规划和导航能力。使用这些能力时，位置、搜索、路线、设备和网络等信息可能由百度 SDK 按其自身隐私政策和 SDK 个人信息处理规则处理。

Wear OS 同步使用 Google Play services Wearable Data Layer。该服务在设备配对和数据传输过程中可能按 Google 的相关政策处理必要的连接与服务数据。

请同时查阅相关第三方服务提供商的隐私政策。第三方 SDK 的数据处理行为由对应服务提供商负责。

## 6. 数据存储、共享与安全

- 应用设置、快捷地址和部分缓存主要保存在用户设备本地。
- 本项目不建设后台服务保存位置轨迹、搜索历史或账号资料。
- 除调用上述第三方地图、定位、导航和设备连接服务所必需的处理外，我们不会出售、出租或向广告商共享个人信息。
- 用户可通过系统设置撤销权限、清除应用数据或卸载应用，以删除设备本地保存的数据。

## 7. 权限说明

实际请求的权限以安装包清单和 Android 系统授权弹窗为准。应用可能使用：

| 权限/能力 | 用途 |
| --- | --- |
| 精确/大致位置 | 定位、周边搜索、路线规划和导航 |
| 网络状态与互联网 | 访问地图、搜索、路线规划与导航服务 |
| 蓝牙扫描 | 辅助设备连接或定位相关能力（如系统支持） |
| 前台服务、通知、唤醒锁 | 导航期间保持服务运行并显示导航状态 |
| Wear OS 设备连接 | 向已配对手表同步必要的导航状态 |

拒绝位置或网络权限后，地图、搜索、路线规划和导航等功能可能无法正常使用。

## 8. 儿童隐私

本应用不是面向儿童设计的产品。我们不会故意收集儿童的个人信息。如监护人认为儿童在使用本应用或第三方服务时提供了个人信息，请通过下方联系方式联系我们。

## 9. 政策更新

如应用功能、第三方 SDK 或数据处理方式发生重要变化，本政策可能更新。更新后的版本将发布在本 GitHub 仓库中，并以本页的生效日期为准。
